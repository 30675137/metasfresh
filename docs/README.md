## 📝 文档规范

项目文档遵循以下规范：

1. **Markdown 格式** - 所有文档使用 Markdown 编写
2. **中英文混排** - 支持中英文，专业术语保留英文
3. **清晰结构** - 使用标题、列表、代码块等组织内容
4. **实用示例** - 提供可运行的代码示例
5. **持续更新** - 随项目更新及时维护文档
