# metasfresh 系统架构

## 📐 总体架构

metasfresh 采用现代化的微服务架构，基于 Java、React 和容器化技术构建。

```
┌─────────────────────────────────────────────────────────────┐
│                        用户界面层                            │
├──────────────────┬──────────────────┬──────────────────────┤
│   Web UI         │   Mobile UI      │   API Clients        │
│   (React)        │   (React)        │   (REST/WebSocket)   │
└────────┬─────────┴────────┬─────────┴──────────┬───────────┘
         │                  │                     │
         └──────────────────┴─────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────────┐
│                      应用服务层                              │
├──────────────────┬──────────────────┬──────────────────────┤
│   WebUI API      │   App Server     │  External Systems    │
│   (Spring Boot)  │   (Spring Boot)  │  (Apache Camel)      │
└────────┬─────────┴────────┬─────────┴──────────┬───────────┘
         │                  │                     │
         └──────────────────┴─────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────────┐
│                      基础设施层                              │
├──────────────────┬──────────────────┬──────────────────────┤
│   PostgreSQL     │   RabbitMQ       │   Elasticsearch      │
│   (数据库)        │   (消息队列)      │   (搜索引擎)          │
└──────────────────┴──────────────────┴──────────────────────┘
```

## 🏗️ 核心组件

### 1. 前端层

#### Web UI
- **技术栈：** React 16.14+, Redux, Webpack 5+
- **职责：** 桌面端用户界面
- **端口：** 80 (HTTP), 443 (HTTPS)
- **特性：**
  - 响应式设计
  - 实时数据更新
  - 多语言支持
  - 权限控制

#### Mobile UI
- **技术栈：** React, Redux
- **职责：** 移动端用户界面
- **端口：** 8880
- **特性：**
  - 移动优化界面
  - 离线支持
  - 扫码功能
  - 快速操作

### 2. 应用层

#### WebUI API
- **技术栈：** Spring Boot 3.x, Java 17+
- **职责：** 为前端提供 REST API
- **端口：** 8080
- **调试端口：** 8789
- **主要功能：**
  - REST API 接口
  - WebSocket 实时通信
  - 认证授权
  - 数据验证

#### App Server
- **技术栈：** Spring Boot 3.x, Java 17+
- **职责：** 核心业务逻辑处理
- **端口：** 8282
- **调试端口：** 8788
- **主要功能：**
  - 业务流程引擎
  - 数据处理
  - 报表生成
  - 批处理任务

#### External Systems
- **技术栈：** Apache Camel
- **职责：** 外部系统集成
- **端口：** 8095
- **主要功能：**
  - EDI 集成
  - 第三方 API 对接
  - 数据同步
  - 消息转换

#### EDI Service
- **职责：** 电子数据交换
- **端口：** 8184
- **主要功能：**
  - EDI 文件处理
  - 格式转换
  - 数据映射

### 3. 基础设施层

#### PostgreSQL
- **版本：** 14+
- **职责：** 主数据库
- **端口：** 5432
- **特性：**
  - ACID 事务
  - 复杂查询
  - 触发器和存储过程
  - 全文搜索

#### RabbitMQ
- **版本：** 3.9.13+
- **职责：** 消息队列
- **端口：** 5672 (AMQP), 15672 (管理界面)
- **用途：**
  - 异步任务处理
  - 服务解耦
  - 事件驱动架构
  - 负载均衡

#### Elasticsearch
- **版本：** 7.17.8
- **职责：** 搜索引擎
- **端口：** 9200 (HTTP), 9300 (Transport)
- **用途：**
  - 全文搜索
  - 日志分析
  - 数据聚合
  - 实时索引

## 🔄 数据流

### 典型请求流程

```
用户操作 (Web UI)
    │
    ▼
1. HTTP 请求 → WebUI API (8080)
    │
    ▼
2. 业务验证 → App Server (8282)
    │
    ├─→ 3a. 数据查询 → PostgreSQL (5432)
    │
    ├─→ 3b. 搜索请求 → Elasticsearch (9200)
    │
    └─→ 3c. 异步任务 → RabbitMQ (5672)
    │
    ▼
4. 响应数据 ← WebUI API
    │
    ▼
5. 界面更新 (Web UI)
```

### 异步处理流程

```
业务触发
    │
    ▼
1. 发送消息 → RabbitMQ
    │
    ▼
2. 消费者监听 ← App Server
    │
    ▼
3. 业务处理
    │
    ├─→ 数据库操作 (PostgreSQL)
    │
    ├─→ 搜索索引 (Elasticsearch)
    │
    └─→ 外部系统 (External Systems)
    │
    ▼
4. 完成通知 → WebSocket → 前端更新
```

## 🔐 安全架构

### 认证授权
```
用户登录
    │
    ▼
1. 用户凭证验证 (WebUI API)
    │
    ▼
2. 生成 JWT Token
    │
    ▼
3. Token 存储 (Redis/内存)
    │
    ▼
4. 请求携带 Token
    │
    ▼
5. Token 验证 (每个请求)
    │
    ├─→ 权限检查
    └─→ 角色验证
```

### 数据安全
- **传输加密：** HTTPS/TLS
- **数据加密：** 敏感字段加密
- **访问控制：** 基于角色的权限控制 (RBAC)
- **审计日志：** 操作记录追踪
